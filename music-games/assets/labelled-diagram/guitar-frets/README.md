# Guitar Strings and Frets

Original square chord diagram for the Music Games Label game. The nut is at the top. Strings run from left to right: low E, A, D, G, B, high E. Five fret spaces run down from the nut. The diagram has no visible text or fret numbers.

The PNG is embedded for portable downloads. The SVG is the editable source. Coordinates use an 800 by 800 canvas. Revision 2 rotated the original horizontal diagram clockwise. Revision 3 enlarges the fretboard by 1.55 horizontally and 1.08 vertically about the centre, and removes text. Older built-in shared links migrate their pin positions with the artwork.

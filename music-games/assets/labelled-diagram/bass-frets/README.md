# Bass Guitar Strings and Frets

Original artwork for the Music Games Label game. SVG is the editable source. PNG is embedded in the built-in activity to keep downloads portable. Coordinates refer to an 800 by 800 square canvas.

Place each pin on the named string in the correct fret space. The nut is at the top; strings are E, A, D and G from left to right.

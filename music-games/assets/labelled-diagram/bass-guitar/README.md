# Parts of the Bass Guitar

Original four-string electric bass illustration for the Music Games Label game. The editable SVG includes a contoured red body, cream pickguard, long rosewood fingerboard with 22 frets, four inline tuning machines, two single-coil pickups and a four-saddle bridge. PNG is embedded for portable activity downloads. Coordinates use an 800 by 800 square canvas.

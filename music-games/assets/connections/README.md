# My Music Online Connection activities

18 separate Music Games Connection games adapted from the Connect Fours linked on My Music Online. Source card text and group labels are preserved, with leading/trailing whitespace removed. Each game contains four groups of four cards. The Music Games Connection rules and default muted audio apply. No original ClassTools interface, scripts or artwork are included.

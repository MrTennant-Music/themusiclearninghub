# Door code order props

The built-in ImageGen tool generated each prop separately with a transparent background. The source images were fitted to 512 × 512 transparent canvases for the room layout.

Shared prompt: a single photorealistic prop for a UK secondary school music escape room. Centre the whole object on a square, fully transparent canvas with clearance around the outline. Use worn textures, soft light from the upper left, and restrained three-quarter perspective. No floor, room, cast ground shadow, labels, logos, watermarks, numbers, or legible text.

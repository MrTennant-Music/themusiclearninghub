# AVL Black Pearl — Composition Studio rock kit

Samples: AVL Drumkits / Black Pearl by Glen MacArthur (AV Linux).
Source website: http://www.bandshed.net/avldrumkits/
User-supplied collection: drumkit-kits-main/avl-black-pearl, 29 October 2026.

Changes: WAV converted to AAC-LC 96 kb/s M4A, preserving the complete duration,
original sample rate/channels, and all five velocity layers. No normalisation,
trimming, effects or pitch changes were baked into the files.

Mapping (app MIDI -> original sample prefix):
36 Kick -> 36
38 Snare -> 38 (centre)
42 Closed hi-hat -> 42
44 Pedal hi-hat -> 44
46 Open hi-hat -> 46 (source kit's semi-open articulation)
51 Ride -> 51 (tip)
49 Crash -> 49 (crash 1)
50 High tom -> 48 (hi-mid tom)
47 Mid tom -> 45 (tom centre)
45 Low tom -> 41 (floor tom centre)

The three toms use distinct drums rather than separate centre/edge hits on one
instrument. Rim, ride bell, additional cymbals and other percussion are excluded.
